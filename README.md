## Problem-Solving Framework

For each problem, I try to answer:

1. What exactly is being asked?
2. What are the constraints?
3. What is the simplest working approach?
4. Can the approach be optimized?
5. What is the time complexity?
6. What is the space complexity?
7. What edge cases can break the solution?

## Time & Space Complexity

Understanding complexity is a core part of the practice.

| Complexity | Example                      |
| ---------- | ---------------------------- |
| O(1)       | Constant-time lookup         |
| O(log n)   | Binary search                |
| O(n)       | Single-pass traversal        |
| O(n log n) | Efficient comparison sorting |
| O(n²)      | Nested-loop solutions        |

## Run the Code

Clone the repository:

```bash
git clone https://github.com/akshatas28/java-problem-solving.git
```

Move into the repository:

```bash
cd java-problem-solving
```

Compile a Java file:

```bash
javac FileName.java
```

Run it:

```bash
java FileName
```
